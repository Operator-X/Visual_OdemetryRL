## Evaluation protocol (2026-10-02)
- Score a run by the mean over its **last >= 3 snapshots** and **>= 3 seeds**; never the final checkpoint alone
  (one run's TUM ATE moves +-7% between consecutive snapshots with no trend).
- Report the paper-style mean ATE on the commonly finished TUM sequences **and** the per-sequence geometric-mean ratio
  to the rules, plus finished sequences and failures. TUM is a development set (we tuned SVO and chose methods on it).
- Details and the full bias audit: `docs/research_plan.md` ("Evaluation protocol from now on").
